# Работа с удаленными репозиториями в Git

## Подключение к удаленному репозиторию
```bash
git init  # Инициализация Git (если ещё не сделано)
git remote add origin https://github.com/your_username/my_project.git  # Добавление удаленного репозитория
git remote -v  # Проверка подключенного репозитория
```

## Отправка изменений в удаленный репозиторий
```bash
git add .  # Добавление всех файлов в индекс
git commit -m "Добавлены инструкции по работе с удаленными репозиториями"  # Создание коммита
git push -u origin main  # Отправка изменений в основную ветку (main)
# Если основная ветка называется master, используйте:
# git push -u origin master
```

## Работа с ветками
```bash
git checkout -b feature/dz  # Создание новой ветки (замените feature/dz на нужное имя)
git add .  # Добавление изменений в индекс
git commit -m "Обновлены инструкции для задания"  # Фиксация изменений
git push -u origin feature/dz  # Отправка ветки в удаленный репозиторий
```

## Создание Pull Request
1. Перейдите в ваш репозиторий на GitHub.
2. Нажмите кнопку "Compare & pull request".
3. Укажите заголовок и описание Pull Request (например: "Обновлены инструкции").
4. Нажмите "Create pull request".
5. Ожидайте рассмотрения Pull Request.

Теперь ваш Pull Request создан и готов к ревью!
