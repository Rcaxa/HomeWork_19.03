# Работа с удаленными репозиториями и создание Pull Request

## 1. Связывание локального репозитория с удаленным
# Перейдите в свой локальный проект
cd path/to/my_project

# Инициализируйте Git (если ещё не сделано)
git init

# Добавьте удаленный репозиторий
git remote add origin https://github.com/your_username/my_project.git
# Замените your_username и my_project на ваши данные

# Проверьте, что удаленный репозиторий добавлен
git remote -v


## 2. Отправка изменений в удаленный репозиторий
# Добавьте все файлы в индекс Git
git add .

# Сделайте коммит
git commit -m "Добавлены инструкции по работе с удаленными репозиториями"

# Отправьте изменения в удаленный репозиторий
git push -u origin main
# Если основная ветка называется master, используйте:
# git push -u origin master


## 3. Работа с ветками
# Создание новой ветки
git checkout -b feature/dz
# feature/dz — это имя вашей ветки

# Внесите изменения и закоммитьте их
git add .
git commit -m "Добавлены инструкции по работе с удаленными репозиториями"

# Отправьте ветку на GitHub
git push -u origin feature/dz


## 4. Создание Pull Request
# После отправки ветки на GitHub:
# 1. Зайдите на страницу вашего репозитория на GitHub.
# 2. Нажмите кнопку "Compare & pull request".
# 3. Укажите название Pull Request (например: "Добавлены инструкции").
# 4. Напишите описание Pull Request.
# 5. Нажмите "Create pull request".

# Теперь ваш Pull Request создан и ожидает рассмотрения!
